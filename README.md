# Music-Player

This project is a custom audio player built using HTML, CSS, and JavaScript.
It allows users to play and pause audio, track playback progress, and seek to different positions using a custom progress bar.

<h1>🚀 Features</h1>

Play and pause audio using a custom control button

Dynamic progress bar that updates with the audio playback

Seek audio by dragging the progress slider

Automatic icon toggle between play and pause

Smooth and user-friendly audio controls

<h1>🛠️ Technologies Used</h1>

HTML5 (Audio Element)

CSS

JavaScript (DOM manipulation & event handling)
